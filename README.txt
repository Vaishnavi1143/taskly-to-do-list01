PERSONAL PORTFOLIO WEBSITE

1. Extract the ZIP file.
2. Open index.html in Chrome, Edge, or another browser.
3. Edit the placeholder information before submitting:
   - Your name and the details provided so far have already been added. Review them and edit if needed.
   - Review the About section, city, email, and education details.
   - Adjust skills and progress bars to reflect your real skills.
   - The Projects section is written honestly for a beginner: learning journey, practice in progress, and future projects.
4. Keep index.html, style.css, and script.js in the same folder.

FEATURES INCLUDED
- Home page with name and introduction
- About Me section with personal and academic details
- Education section
- Technical and non-technical skills
- Projects section
- Contact form with JavaScript validation (no backend)
- Navigation menu connecting all sections
- Responsive layout for mobile, tablet, and desktop
- Dark/light mode toggle
- Mobile navigation menu
- Smooth scrolling

Note: This is a front-end project. The contact form validates input in the browser but does not send messages to a server.
